Горизонтальний варіант масштабований із результату генератора 1672×941, а вертикальний кадрований із тієї ж фотографії. Вони призначені для перевірки адаптивності та оптимізації Next Image; деталей реальної 4K-фотографії масштабування не додає.

No people, no text, no watermark. Landscape composition 16:9, ideally 4080 x 2296 or highest supported landscape resolution. Building centered with enough room for both horizontal and vertical crop. Natural believable photography, soft colors, not oversaturated.»

Nunito завантажено з Google Fonts; ліцензія SIL Open Font License збережена в `public/fonts/OFL.txt`. Шрифт обслуговується локально через `next/font/local`.


## Уточнення погоди — 2026-09-08

Власник надав точні координати школи: `50.387776170682585, 29.5044316558184`. Попередня точка `50.38845, 29.50687` розташована приблизно за 188 м. Під час порівняння живих відповідей Open-Meteo обидва запити повернули ту саму комірку `50.375, 29.5`, часовий пояс Europe/Kyiv та однакові погодні коди. Для 17:45 провайдер повідомляв код 2, 21.2 °C, опади 0 мм; добовий код на 8 вересня — 45 (туман), добові опади — 0 мм. Це знімок відповіді провайдера, не спостереження шкільної метеостанції.

Виправлено помилкове відображення всіх добових кодів ≥4 як дощу; поточна погода й добовий прогноз тепер використовують одну таблицю WMO. Код дня означає найбільш виражене явище за добу, а не погоду саме зараз. Коди 0/1/2/3 мають окремі іконки; враховано ніч. Ключ погодного кешу оновлено після зміни координат.

Джерело семантики кодів, комірок і добових прогнозів: [Open-Meteo API documentation](https://open-meteo.com/en/docs). Поточні умови Open-Meteo розраховані погодними моделями, тому можуть відрізнятися від інших сервісів. Синхронне порівняння актуальних прогнозів Google, Sinoptik та Meteofor не виконувалося; пошукові витяги мають застарілі дати й для цього непридатні.


## Перехід на WeatherAPI.com — 2026-09-08

За вказівкою власника Open-Meteo замінено на WeatherAPI.com. [Документація API](https://www.weatherapi.com/docs/) та [коди стану погоди](https://www.weatherapi.com/docs/weather_conditions.json). Запит forecast.json використовує точні координати школи, days=7, lang=uk. Живий запит із наданим ключем успішно повернув 7 днів. Найближча точка в базі провайдера названа Vysokoye (50.383, 29.517), часовий пояс Europe/Kyiv; у віджеті лишається локальна назва Йосипівка. Українські підписи беруться з WeatherAPI; попередня таблиця WMO більше не використовується. Історичні записи перевірки Open-Meteo вище стосуються попереднього провайдера.
