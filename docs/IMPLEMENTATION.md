# Стан реалізації

Реалізація продовжена з наявного стану за `AGENTS.md`. У суперечливих пунктах застосовано фінальні уточнення ТЗ: ролі `admin`, `class_1`…`class_4`, вхід із підтвердженим Google email без автоматичних прав, редагування лише метаданих фото.

## Реалізовано

- Публічні сторінки школи, історії, шкільного життя, чотирьох класів, галерей та архіву. SSG/ISR, SEO metadata, sitemap, адаптивний дизайн і локальний шрифт.
- Розклад 6 × 6 із часовими слотами, поточним тижнем Europe/Kyiv, окремим збереженням тижнів і редагуванням наступного тижня у вихідні.
- Спільні записи галереї/архіву, URL-фільтри, курсорне завантаження, віртуалізація, lightbox із керуванням фокусом.
- Auth.js/Google, актуальні серверні перевірки дозволів, адмін-кабінет, RHF/Zod, транзакції та аудит змін.
- Cloudinary upload із перевіркою типу/розміру, оптимізована видача, очищення метаданих зображень, черга повторного видалення.
- Погода WeatherAPI.com, дружні loader/error/toast, клавіатурне керування та reduced motion.
- Міграції Drizzle, development seed, production bootstrap, очищення файлів і застарілих логів. Налаштування описано в README.

## Перевірка

- `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
- 30 модульних/інтеграційних тестів: дозволи, календар, реальні PostgreSQL-операції через PGlite, мутації, відкат і cleanup.
- `npm run test:e2e`: 28 сценаріїв у Chromium, Firefox, WebKit mobile/tablet; публічна навігація, розклад, архів, lightbox, фокус, адаптивність і захищені маршрути.
- `npm audit --audit-level=moderate`: 0 відомих вразливостей на момент перевірки.

## Зовнішні налаштування

Без облікових даних Neon, Google OAuth та Cloudinary доступний позначений демонстраційний режим. Живі вхід, upload і production-міграції потребують значень `.env.local`; автоматичні тести не доводять справність неналаштованих зовнішніх акаунтів. Погода в E2E підмінена детермінованою фікстурою.

Офіційні адреси соцмереж не надані: їх додають у `SOCIAL_LINKS`. Джерела історичних фактів та походження демонстраційної ілюстрації наведено в `SOURCES.md`. Імена педагогів і фотографії реальних дітей не вигадані.
